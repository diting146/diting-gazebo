  0.4 m。原完整单车入口和独立建图 launcher 删除，建图通过同一双车入口
  `localization:=lio slam:=True` 选择。启动方法见根 README。

## 构建和回归

在独立临时工作区，将本次仿真包、YAstar 插件及**远端原版**
`fake_vel_transform` 一起构建，依赖其余已安装工作区包。不是从空系统进行的
全量依赖安装验证。三个包的安装前缀均确认指向此次临时构建。

```bash
colcon build --base-paths src \
  --packages-select tdt_yastar_planner sentry_sim_bringup fake_vel_transform \
  --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
colcon test --base-paths src \
  --packages-select tdt_yastar_planner sentry_sim_bringup \
  --return-code-on-test-failure
colcon test-result --verbose
```

- 三个包构建成功。YAstar 9 项 GTest、仿真包 25 项 pytest 全部通过，0 failures、
  0 errors、0 skipped；colcon 汇总 35 项包含 GTest 的 CTest 包装项。
- 15 个发布 Python 文件通过 ament_flake8；Python 语法、XML、YAML 解析通过。
  LIO/GT 的源码及安装配置 local/global costmap 半径均为 0.4 m。
- pre-commit 工具未能安装：下载的 PyYAML wheel 校验不匹配，未绕过校验。
  因此不声称完整 pre-commit hooks 通过；已执行上述静态检查及 Git 空白检查。

## 独立运行验证

使用专用 ROS_DOMAIN_ID 和 IGN_PARTITION，无界面 Gazebo 世界及真实模型；
双车入口使用 `start_simulator:=False spawn_delay:=3 spin_speed:=0 use_rviz:=False`。
默认 GUI 场景包含及命名空间配置由启动契约测试覆盖，未做本轮 GUI 目视验收。

| 检查 | 结果 |
| --- | --- |
| 两车出生坐标 | 哨兵 `(-5.3, 3.0)`，手动车 `(5.3, -3.0)` |
| 激光及里程计 | 两车里程计和哨兵 obstacle_scan 实际收到 |
| lifecycle | planner_server、controller_server、bt_navigator、velocity_smoother 均 active |

未对用户已有仿真实例发送控制或停止命令。

## 验证边界

本轮证明此远端组合可构建、启动、完成一条短路线并控制手动车；未重做人工键盘、
动态堵路、持续无路、取消停车、自旋、建图质量或所有 Theta*/GT 场景的动态验收。

开发工作区中另有 `fake_vel_transform` 的停车/缓存修复，本次未上传，不能据此
声称远端具备这些修改。当前仿真网关可处理其输入断流，但不等于验证了上游所有
取消/缓存路径。手动初值覆盖和定位质量保护按用户要求暂不处理；LIO 网关的
里程计就绪检查不代表 small_gicp 匹配质量检测。
